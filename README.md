# Bowcasting

A client-side Minecraft Fabric mod that adds animated magical spell effects to bows, crossbows, and arrows.

Bowcasting adds animated spell circles while charging ranged weapons, along with magical rune trails for fired arrows. Effects include custom textures, multi-stage animations, configurable scale and rotation speed, and optional dynamic lighting.

## Features

* ✨ Animated multi-stage spell effects

* 🏹 Supports bows and crossbows in first- and third-person

* 🔮 Animated rune particles on fired arrows

* 💡 Dynamic lighting through LambDynamicLights when available

* 🎚️ Configurable spell scale

* 🎚️ Configurable rotation speed

* 🔘 Individual toggles for bow, crossbow, and projectile effects

* 🖥️ Cloth Config settings screen through Mod Menu

* 🎮 Designed for Minecraft 1.20.1 + Fabric

## Configuration

Bowcasting provides configuration options through Mod Menu, including:

* **Bow Effects**: Enables or disables spell effects when using bows.

* **Crossbow Effects**: Enables or disables spell effects when using crossbows.

* **Projectile Effects**: Enables or disables rune effects on fired projectiles.

* **Scale Multiplier**: Adjusts the size of spell effects.

* **Rotation Speed Multiplier**: Adjusts the speed of spell rotation.

Mod Menu and Cloth Config are optional. Bowcasting can be used without them, but the in-game configuration screen will not be available.

## Compatibility

Bowcasting is designed for:

* Minecraft 1.20.1

* Fabric

* Java 17+

LambDynamicLights is an optional integration. When installed, active spell effects can emit dynamic light.

## Installation

Install the Bowcasting `.jar` into your Minecraft `mods` folder.

For full dependency and compatibility information, see the project's Modrinth page.
